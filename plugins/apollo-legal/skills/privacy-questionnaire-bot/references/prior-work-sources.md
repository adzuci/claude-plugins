# Prior Work Sources

Use these sources in Step 3 to find reusable prior answers before drafting.

## Canonical Reference Repositories (Check These First)

These are the master indexes of completed Apollo questionnaires, and the fastest way to find a reusable prior answer for the same customer or a similar questionnaire type.

- **Questionnaire Repository Index (Google Doc)** — running log of every completed vendor/customer security/legal/compliance questionnaire, organized by team member, with Jira ticket key, date, vendor/customer name, and a direct Google Drive folder link for each. Use it to (a) check whether this customer has been done before, and (b) jump straight to the source folder for a similar past deal.
  `https://docs.google.com/document/d/18mFLuek4kNdJW8bGndzkDAtDrVwHIQruN3VDhQVCSbg/edit`

- **Completed Questionnaires Drive Folder** — shared Drive folder containing the actual completed questionnaire files referenced in the index above.
  `https://drive.google.com/drive/folders/1JD_1lZhF8RuWA51jPHwQ4BJU5Tk8OSly`

How to use them: match on customer name first (e.g., a repeat customer like Pluxee, HighRadius, Ensono, Immuta, or Uber that appears multiple times), then on questionnaire type. Open the linked folder, pull the closest prior answers, and adapt rather than redrafting from scratch. Always note the source ticket in your citation (e.g., `Based on: LEGAL-1286 Pluxee questionnaire`).

## Broader Search

Then search in parallel across:

**Jira** — Search for:

- Prior tickets from the same customer
- Similar questionnaire types (e.g., "Vendor Security Assessment", "SOC 2", "DPA")
- Key question phrases (e.g., "data residency", "encryption at rest", "sub-processors")

**Glean** — Search for:

- Security whitepapers, privacy overviews, architecture docs
- Policy docs: InfoSec, Privacy, Data Retention, Access Control, Incident Response
- Compliance docs: SOC 2 report summaries, ISO certs, DPA templates
- Previous completed questionnaire answer banks

**Google Drive** — Look for:

- The actual questionnaire file (Excel/Doc/PDF) attached to the deal
- Previous completed questionnaires for this customer or similar deals
- Deal-specific folders (by customer name or opportunity ID)

## Priority Rules for Conflicting Info

1. Newest official doc > older Jira comment
1. Security whitepaper > ad-hoc Slack message
1. Note conflicts briefly and flag for confirmation
