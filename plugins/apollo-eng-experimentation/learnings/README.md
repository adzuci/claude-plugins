# Learning cards

Anonymized notes from real runs of the experiment lifecycle skills, one file per
card under `<skill>/<YYYY-MM-DD>-<slug>.md`. Skills draft a card at the end of a
run and, with the user's approval, open a draft PR that adds it here. The card
format and anonymization rules are in
`../references/experiment-lifecycle-conventions.md`, section 7.

Cards never change a skill by themselves. Maintainers read them, decide which
patterns recur, and fold the change into the skill in a separate PR.
