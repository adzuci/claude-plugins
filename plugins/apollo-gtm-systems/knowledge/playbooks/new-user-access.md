# Playbook: requesting access to GTM stack tools

Use this playbook when onboarding as a new Apollo employee or after a role change that requires access to new tools.

## Standard process

Most tool access can be requested directly through the Lumos App Store: https://app.lumosidentity.com/app_store (also accessible via `/lumos` in Slack). Lumos handles provisioning for the majority of Apollo's SaaS tools with manager approval built in.

For tools not in Lumos, or for specific permission changes, large batch access requests, or team/department-level changes, use the RS JIRA Service Desk:

1. Go to https://apollopde.atlassian.net/servicedesk/customer/portal/8 and select "Access Request"
2. Fill in: your name, Apollo email address, role and team, the tool(s) you need, and a brief reason
3. Standard access is provisioned within 1-2 business days of ticket submission

## Tool-specific notes

**Salesforce**
Specify whether you need a standard user license or a specific profile (e.g., Sales Cloud User, read-only, system admin). Standard profiles are provisioned by GTM Systems; non-standard profiles require additional review.

**Gong**
Gong seats are limited. Include your manager's written approval (a Slack message or email forward is acceptable) in the RS ticket. Viewer access is the default; recorder or manager access requires justification.

**Chili Piper**
Routing setup is not automatic. Include your intended routing group (e.g., SMB AE, ENT AE, CSM) in the ticket. GTM Systems will configure the routing rule during provisioning.

**Ironclad**
Access is provisioned for legal, finance, and AE roles involved in contract workflows. Include your role and the specific contract workflow you need access to.

## Who provisions what

| Tool | Provisioned by |
|---|---|
| Salesforce (non-standard profiles) | GTM Systems |
| Gong | GTM Systems |
| Chili Piper | GTM Systems |
| Ironclad | GTM Systems |
| Salesforce (standard profile) | GTM Systems via RS ticket |
| Slack | IT / HR |
| Google Workspace | IT / HR |
| Notion | IT / HR |

## After access is granted

Test access before closing the ticket. If something is missing or misconfigured (wrong profile, missing routing group), add a comment to the ticket rather than opening a new one.
