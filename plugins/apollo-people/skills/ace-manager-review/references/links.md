# Apollo Reference Links — ACE Manager Review

Centralised list of external resources the skill needs to consult during a
review. Update this file when links change — the main `SKILL.md` should not
hardcode these URLs.

## Company OKR Directory

Start here to understand what the direct report was accountable for. These sheets list
company-wide OKRs, DRI assignments, and links to team-level KR tracking documents.

- **FY27 Q1 OKRs (1 Feb – 30 Apr 2026):** https://docs.google.com/spreadsheets/d/1ZgIqAwUv4A53Wl4m2bf-mKgzAqhE-dBqFX0N20s7Cd0/edit?gid=1400704651#gid=1400704651
- **FY27 Q2 OKRs (1 May – 31 Jul 2026):** https://docs.google.com/spreadsheets/d/1ZgIqAwUv4A53Wl4m2bf-mKgzAqhE-dBqFX0N20s7Cd0/edit?gid=170691627#gid=170691627

Search for the direct report's name and their team. Follow any linked tracking docs to
find specific KR progress. When following linked docs, check that the data shown
is from the correct calendar period (February–July 2026) — some trackers show
rolling figures or cumulative data that may include periods outside the review window.

## Apollo Career Framework

**Apollo Career Framework (draft — confirm final version before launch):**
https://docs.google.com/spreadsheets/d/1PFHL5XYZhzxmRLQ4H6qseJHveaxadj73FwgmHfNtC7U/edit?gid=147060806#gid=147060806

The skill also reads the repo-root copy at `/references/career-framework/company-framework.md`,
which is the shared reference used across all people skills. Use that file for the Level Question,
scope descriptors, and craft expectations at the report's level.

Find the report's track (IC or manager) and their stated level. Note:

- Expected scope, autonomy, and craft competencies at their current level
- The Level Question for their level (the single yes/no readiness check)

Use this to anchor the Growth, Development & Mastery section — particularly the concrete example
of what stronger execution at their level would have looked like.

Note that this framework is a draft proposal — if a finalised version has been
published, use that instead.
