# Connectivity Test — 1:1 Prep

Run this quick test after intake, before any real searching, to confirm each connector responds.

## How to test

Make one minimal search query against each connector using the direct report's name — just enough to confirm the connector responds:

- **Slack:** Search for their name
- **Notion:** Search for their name
- **Glean:** Search for their name (if available)
- **Google Drive:** Search for their name (if available)

## Report status

Show the manager what you can access:

______________________________________________________________________

Here's what I can access:

- ✅ **Slack** — connected, found messages
- ✅ **Notion** — connected, found pages
- ⚠️ **Glean** — not connected (optional — I'll skip this)
- ⚠️ **Google Drive** — not connected (optional — I'll skip this)

______________________________________________________________________

Use these markers:

- ✅ if the connector returned results
- ⚠️ if connected but no results, or if optional and not connected
- ❌ if required and not working

If both Slack and Notion are ❌, recommend enabling them at [claude.ai/customize/connectors](https://claude.ai/customize/connectors) for the best results. But don't dead-end the manager — offer to continue on pasted content instead:

> "I can't reach Slack or Notion right now. For the richest prep, enable them at the link above and type 'ready' again. Otherwise, paste any relevant messages, 1:1 notes, or links here and I'll work with those — just type 'go' to continue."
