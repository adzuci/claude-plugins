# Connector Setup — 1:1 Prep

Share these instructions with the manager when connectors need to be enabled.

______________________________________________________________________

Before we get started, I need to check that the right connectors are enabled so I can search your tools automatically.

**Here's how to enable them — takes about 2 minutes:**

1. Open this link: **[claude.ai/customize/connectors](https://claude.ai/customize/connectors)**
1. Find each connector in the list and toggle it **on**
1. If it asks you to authenticate, follow the prompts

**You'll need these:**

| Connector | What I'll use it for |
|---|---|
| **Slack** | Kudos, shoutouts, project channels, help requests |
| **Notion** | 1:1 notes, OKR pages, project docs |

**Optional but helpful:**

| Connector | What I'll use it for |
|---|---|
| **Glean** | Cross-platform search for broader context |
| **Google Drive** | 1:1 notes docs, project docs, OKR sheets |

> **Note on Glean:** Glean requires a separate license, so not everyone has access. If you don't see it in your connector list or it won't enable, that's expected — skip it. I'll still gather plenty of context from Slack and Notion.

Once they're on, come back here and type **"ready"** and we'll get started.

> **Can't find a connector or don't have access?** No problem — type "ready" anyway and tell me which ones are missing. For anything I can't access, you can paste content or links directly into the chat.
