# apollo-people

People Enablement skills for Apollo employees — performance reviews, career development, benefits, payroll, and time off.

## Skills

- **`ace-mid-year-review`** — Helps an Apollo employee draft their ACE mid-year self-review for submission in CultureAmp. Acts as a thinking partner, searches connected tools for evidence, and produces a first-person draft across the Impact, Ownership, and Growth & Mastery sections. Core connectors: Notion, Slack, Google Drive (and Glean if licensed). Engineering employees also benefit from Jira and GitHub connectors.
- **`onboarding-plan`** — Generates a personalized 15-30-60 day onboarding plan for a new hire, grounded in Apollo's three-phase milestone framework. Triggers when a manager asks to create a ramp plan or shares a role scorecard/job description for a new hire.
- **`benefits`** — Answers questions about Apollo's global benefits programs (medical, dental, vision, 401(k), EAP, commuter/FSA, enrollment windows, QLEs). Routes by employment type: direct employees via the benefits portal, EOR employees to Deel or Remote dashboards.
- **`payroll`** — Helps employees with payslip access, pay schedules, direct deposit setup, tax withholding, pay discrepancies, and deductions. Routes by employment type: direct employees via Darwinbox, EOR employees to Deel or Remote.
- **`time-off`** — Covers Flex PTO, vacation, public holidays by country, and leaves of absence (FMLA, parental, medical, bereavement). Routes by employment type and country; explains manager approval flows and blackout periods.

Each skill's full trigger phrases, scope, and workflow live in its own `SKILL.md`.
