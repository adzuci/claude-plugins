| `ai-infra` | AI infrastructure and model serving |
| `ai-transformation` | AI-driven product transformation initiatives |
| `appsec` | Application security |

| `extension` | Chrome extension |

When the owning team is ambiguous, use Glean to look up the product surface and check the roster or recent PRs for the best match. Do not guess — say "likely `<team>`" and note it is unverified if unsure.
