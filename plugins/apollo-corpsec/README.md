# Apollo Corporate Security Plugin

Self-service skills for Apollo's Corporate Security policies.

## Skills

| Skill | Description |
|-------|-------------|
| comp-device-faq | Quick answers to common device questions (personal laptops, VPN, MFA, BYOD) |
| comp-exception-request | Guides employees through submitting a policy exception request |
| comp-external-storage-policy | Policy on USB drives, external storage, Time Machine, and local backups |
| comp-managed-endpoints-policy | Full Corporate Managed Endpoints Policy reference |

## Usage

Just ask naturally — e.g. "Can I use my personal laptop for work?", "How do I request a USB exception?", "What's Apollo's external storage policy?"
