# apollo-engineering-ops

Cowork-facing engineering enablement skills for Apollo. This plugin is a place for lightweight onboarding and contribution skills that help people understand how the shared skills marketplace works.

## Skills

| Invoke command | Purpose |
| --- | --- |
| `/apollo-engineering-ops:learn-about-skills` | Explain how Cowork skills and plugins work, then offer to help write one and open a PR to add it to this repo |

## What belongs in apollo-engineering-ops

- Skills that teach people how to use, browse, or contribute to Apollo's shared skill marketplace
- Cowork-oriented onboarding flows that are broadly useful across engineering teams
- Contribution helpers that point people at this repo, its plugin structure, and its review process

## What does NOT belong in apollo-engineering-ops

- Repo-specific skills that should live in a project-level `.claude/skills` directory
- Deep operational workflows that already belong in `apollo-ops`
- General coding helpers that are better placed in `apollo-eng`
