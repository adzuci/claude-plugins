# apollo-accounting

Accounting and finance skills for Apollo's Finance team — contract clause analysis, ASC 606 revenue recognition assessment, and Ironclad contract review workflows.

## Skills

- **`contract-clause-analyzer`** — Analyzes contracts clause-by-clause against Apollo's standard templates and flags deviations (RED/YELLOW/GREEN). Accepts direct file uploads or scans Ironclad for pending contracts. Classifies contract type (MDSA, Order Form, NDA, Consulting Agreement, Reseller Addendum, Competitor Buyout, Upsell Order), loads the appropriate playbook, and produces a flagged report plus an ASC 606 revenue recognition assessment spreadsheet. Requires the Ironclad connector. Trigger phrases: "check this contract", "flag anything unusual", "contract review", "non-standard clauses", "is this our standard language", "scan Ironclad for contracts".

Each skill's full trigger phrases, scope, and workflow live in its own `SKILL.md`.
