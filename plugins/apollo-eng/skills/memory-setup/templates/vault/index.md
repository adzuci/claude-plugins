# Engineering Vault

Central hub for session capture, operational knowledge, and incident learning. Read this first, then navigate via the folders below.

| Folder | Purpose |
| --- | --- |
| **memory/** | Durable knowledge: preferences, patterns, references |
| **sessions/** | Daily logs (YYYY-MM-DD.md), auto-written by SessionEnd hook |
| **raw/** | Inbox for quick captures; librarian agent files daily |
| **incidents/** | Incident reports, postmortems, and follow-ups |
| **runbooks/** | Operational procedures; drift templates to spot reality divergence |
| **handoffs/** | Oncall handoff templates (alerts, risky changes, customer threads) |
| **recipes/** | Quick-reference snippets: symptom → tool → command |
| **wiki/** | Topic-organized knowledge articles (2-hop navigation) |
| **toil-log.md** | Automation candidates (repetitive manual steps) |
