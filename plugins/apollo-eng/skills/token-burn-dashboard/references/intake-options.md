# Intake Options

Ask up to five concise questions before building unless the user already answered them or says to choose defaults. Put the recommended option first when presenting choices.

## Defaults

Use these when the user says "choose defaults":

- Audience and privacy: Private local artifact.
- Timeframe: Previous calendar month bounded by actual available measured data, with full discovered bounds available in the ledger.
- Data thoroughness: Standard thoroughness.
- Visual direction: High-end technical OLED-dark dashboard.
- Output format and runtime: Self-contained HTML plus data ledger.

## Questions

1. Audience and privacy posture: private local artifact, internal shareable artifact, or approved publish target.
1. Timeframe: previous calendar month, actual available timeframe, last 7 days, last 30 days, month-to-date, quarter-to-date, year-to-date, or custom range.
1. Data thoroughness: quick scan, standard thoroughness, or exhaustive local scan.
1. Visual direction: high-end technical OLED-dark dashboard, compact engineering report, or minimal ledger-first dashboard.
1. Output format and runtime: self-contained HTML plus data ledger, local static folder, notebook-style report, or CSV/JSON ledger only.

## Intake Rules

- Do not ask more than five questions.
- Do not ask for secrets, API keys, or browser credentials.
- If the user provides a ChatGPT export or billing export, confirm the local path before reading it.
- If the user requests publishing, confirm the destination and what data may be included before creating or uploading anything.
- If the user asks to skip questions without choosing defaults, proceed with the defaults and state that choice.
