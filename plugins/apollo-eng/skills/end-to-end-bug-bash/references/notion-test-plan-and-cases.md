## Creating the Test Plan page

Use `notion-create-pages`:

```javascript
{
  "parent": { "type": "data_source_id", "data_source_id": "c9bc4007-0e7c-4de0-b345-928cdb95b7ee" },
  "pages": [{
    "properties": {
      "Name": "[Feature Name]",
      "Squad DB": ["[matched Team page URL from 0.2]"],
      "Epic": "[Jira epic URL, if any]",
      "PRD": "[PRD URL, if any]",
      "ERD": "[ERD URL, if any]",
      "Figma": "[Figma URL, if any]",
      "GitHub PRs": "[PR URL(s), if any]"
    },
    "template_id": "114ab2b3b49680a88ee8c67234af2fe6"
  }]
}
```

**Always pass `template_id`, never hand-authored `content`, for this page.** The template's "Add New
Or Execute Test Cases" and "Bugs found" sections are inline database views pre-filtered to "this
page" — only `template_id` reproduces that auto-scoped filter. Hand-authored `<database>` blocks
would show every squad's data, or break outright.

After creation, fill in Scope/Out of scope/Test Environment via `notion-update-page`
(`update_content`, targeted replace against the template's placeholder text under `## Test Strategy`) — leave `## Add New Or Execute Test Cases` and `## Bugs found` untouched.
