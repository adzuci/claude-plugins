Job search as market intelligence

Scrolling job boards is sampling without a model. A senior search goes better when it is run like research: explicit criteria, a repeatable sweep, and a report you can compare week over week.

AudienceStaff / Director / Principal candidates
Artifactcareer plugin
OutputA tier-ranked report in your vault

The senior job market is opaque in a specific way: the roles exist, but the signal about level, compensation, and real remote eligibility is scattered and stale. That is a research problem, and research problems respond to structure.

The career plugin has one skill, /career:market-sweep. It runs a job market intelligence sweep for a senior technical candidate and writes the result into your vault as a dated Markdown report — market intelligence, not a job board dump.

How a sweep works

It starts from a criteria file (career/search-criteria.md in your vault): target titles, location and compensation floor, stack keywords, seniority signals, any priority filter, domain bonuses, and hard exclusions. The first run collects these; later runs confirm and reuse them, which is what makes the reports comparable over time.

The sweep itself covers market conditions for your level, priority companies with confirmed active roles, additional strong matches, stack trends in senior job descriptions, and compensation benchmarks. Claims get verified rather than repeated — a "women-led" filter, for example, means checking who the CEO actually is, and a "Remote US" label means checking the careers page, not the aggregator.

The report is the product. The rank ordering forces the question a spreadsheet of links never asks: which five of these are worth an hour this week?

After the report is written, the skill runs an automated recruiter-review pass over its own output and improves the report in place — the same trick as code review, applied to a research artifact. It then offers to schedule a weekly repeat so the market view stays current instead of being a one-time snapshot.

Honest limitations

It is built on web research, so it inherits the web's noise: compensation data is directional (Levels.fyi, Built In, Glassdoor), listings go stale, and a sweep is a starting point for judgment, not a substitute for it. The defaults are opinionated — remote US, $150k+ base, senior engineering/data titles — though the criteria step generalizes to other disciplines. And the reports land in a local vault on purpose: a job search is exactly the kind of context that should stay in plain files you own.

The practical test: if this is working, week three's report should read differently from week one's — tighter criteria, fewer but better-ranked companies, and a visible trend line instead of a fresh anxiety spiral.
