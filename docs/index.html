Install the plugins

Everything described in these posts is a public plugin. Add the marketplace once, then install what you want.

Claude Code

claude plugin marketplace add adzuci/claude-plugins
claude plugin install memory@adzuci-plugins

Codex

codex plugin marketplace add adzuci/claude-plugins
codex plugin add memory@adzuci-plugins

Each post ends with the install steps and prerequisites for its plugin. Tested primarily on macOS; Linux and Windows compatibility PRs are welcome.
