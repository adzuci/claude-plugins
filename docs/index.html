Each post ends with the install steps and prerequisites for its plugin. Tested primarily on macOS; Linux and Windows compatibility PRs are welcome.

I manage infrastructure teams and use these plugins daily. They keep the context from my AI sessions in plain files I own, where I can read it, search it and delete it.
